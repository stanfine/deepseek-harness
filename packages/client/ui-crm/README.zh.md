# @deepseek-ai/dsh-client-ui-crm

[English](README.md) | 中文

## 概述

此 Web 插件将有界 CRM 查询、标准报表和灵活语义分析呈现为指标卡、无障碍表格和 Apache ECharts 交互视图。通过 [CRM 示例覆盖层](../../../apps/cli/config/examples/crm/cordis.yml)挂载；默认组合不包含它。[CRM 指南](../../../docs/user/guide/crm-monthly.zh.md)负责应用配置和指标口径。

自动选择使用持久化的 `intent`：结构分析仅对完整可加分组使用环图，排行按所选指标将返回分组排序为横向条形图，时间序列使用折线图。无序类别不能使用折线或面积图；不足两个时间桶时使用表格。分组和趋势总数以紧凑上下文展示，不重复指标卡。排序不会补回源分组查询遗漏的数据。

灵活语义分析结果使用独立的持久化 `meta.crmAnalysis` 版本。客户端仅接受请求与结果一致、指标和维度 id 已声明、指标值为有限数或空值、行数与警告有界、对比窗口与完整性事实一致且下钻 id 符合允许格式的元数据。完整持久化包限于发布配置的 1 MiB 结果预算，返回行不得超过标准化请求的上限。展示前会拒绝未知行键、重复列、无效日期和意外持久化字段。图表选择只读取这些已验证值，不重算业务指标：汇总用指标卡，趋势用折线，排行用横条，对比用柱图，不超过八类的完整非负构成用环图，兼容的双指标用柱线图。对比趋势和构成以成对折线或柱图保留两个时期。高密度、多维或不兼容结果保留表格回退，空值保持为图表断点。

## 呈现

按键注册的 `tool.call.toolview` 校验持久化的第 1 版 `meta.crm`，其中包含查询上下文和规范结果。汇总与客户结果显示指标；分组与趋势结果显示图表及精确值表格。模型可指定 `chartType` 和 `metric`；用户无需重新查询，即可切换柱状图、横向条形图、折线图、面积图、饼图、环图或数据表。自动选择使用日历折线或分类对比。文档数、源金额及平均文档金额是分开的指标。负金额保留符号，缺失金额保持缺失。来源口径、日期范围、筛选条件及截断声明始终可见。饼图和环图要求非负可加指标、没有缺失指标或维度、分组精确且无截断，以及桶文档数之和等于来源总数；否则卡片说明原因并回退到对比图。

`crm_analyze` 和 `crm_drilldown` 的按键展示器先通过 `meta.crmAnalysis` 校验器再绘制。汇总行显示为指标卡；分组行根据已验证的意图、列、完整性和对比元数据确定性选图。每个图表都有具名来源表格，保留本期值、对比值、变化、空值和部分值；不可用原因紧邻对应表格值。本期与对比期记录数、覆盖窗口、数据源最早观测日期、指标说明、限制、警告和两个日期窗口都紧邻证据展示。元数据被拒绝时保留通用原始结果。窄屏下指标卡收为单列、指标说明纵向排列、图表降低高度，表格可滚动且不隐藏标签。

点击图形或表格按钮通过标准会话输入动作准备 JSON 限定范围的追问，不自动发送消息，不覆盖已有草稿。语言字典与插槽贡献随插件 fiber 一同移除。插件不负责取数、凭据或模型工具。ECharts 使用按需模块和 SVG 渲染器，仅打包进此可选插件。每个可见卡片负责一个可销毁的实例，并观察容器尺寸。提示框以文本绘制，笛卡尔图提供缩放滑块；全部数值仍可通过无障碍表格读取。模型指定的展示随结果持久化；本地切图和缩放在卡片重新挂载时重置。绘图失败保留表格。不接收任意 ECharts 选项、格式化脚本或外部 URL。

## 模型体验

### CRM 呈现

#### 模型可见内容

模型可见原有 CRM 工具结果。点击语义下钻只准备本地化草稿，其中仅包含日期、指标 id、业务筛选、父级维度值、所选值和下一个业务维度；点击不会提交，只有用户审阅并发送后模型才会看到草稿。物理字段、索引名、查询 DSL、图表几何和选图逻辑不会进入草稿。

#### Token 影响

绘图和切换图表不增加模型 token。发送下钻问题会增加普通用户文本及后续工具结果。

#### KV 缓存影响

图表交互不改变请求历史。发送的追问追加在已有前缀之后。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与后续工作

- 失败、不支持以及缺少有效图表元数据的旧结果保留文字；历史窗口中缺少配对调用的单独结果使用通用工具视图。重新查询即可生成图表。
- 图表不确立币种、订单唯一性、历史完整性或精确的分组贡献。来源警告仍是判断依据。
- 本包不提供全部 ECharts 类型、独立看板、跨调用报表组合或客户端联接。灵活分析目前每个结果只描述一个逻辑数据集；跨来源 CRM 数据联接要等到提供方对身份、时间语义和指标对账建立治理后再实现。新图表系列需要匹配的已验证数据和渲染映射。
