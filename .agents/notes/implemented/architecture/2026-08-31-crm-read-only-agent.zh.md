# Agent Note: 可选 Agent 预设中的有界 CRM 只读查询

Status: implemented

[English](2026-08-31-crm-read-only-agent.md) | 中文

## Problem

CRM 报告需要通过应用 Agent 可重复执行取数。在应用外由助手生成报告不能建立这种能力。通用数据库 DSL 和 Shell 访问也会暴露超出报表任务需要的数据与操作。

## Decision

[CRM 示例](../../../../apps/cli/config/examples/crm/cordis.yml)组合原生工具和业务 Skill，不修改 Agent 循环。部署配置负责精确索引、字段、限额及凭据引用。模型仅提供逻辑数据集、日期和维度筛选。二次数据投影排除非预期记录字段；凭据和底层传输错误不会成为模型可见数据。部署仍负责选择非个人信息字段及设置数据库只读权限。

读取器拒绝不完整响应和预算耗尽的精确统计。分组截断、标识缺失、金额语义未知和实时分页一致性均作为可见限制。Skill 将不支持的队列和品类指标标为不可计算，不使用误导性替代指标。[指南](../../../../docs/user/guide/crm-monthly.zh.md)负责配置与用法。

## Alternatives considered

**通用 Elasticsearch MCP 或原始 DSL。** 这些方式允许更广泛的取数，需要额外策略层才能施加相同的字段及查询限制。有界读取器不需要独立服务。

**在开发会话中手动分析。** 这会产生一次性报告，但不能服务应用用户，也不能保留应用自身的工具执行证据。

## Consequences

示例仅适用于源码工作区，有意提供比通用商业智能更窄的能力。MongoDB、规范化行项目分析、队列查询和时间点一致性需要额外明确的能力。固定周报 Excel 导出器现可通过部署提供的 artifact tool 序列化已完成的汇总报表章节和有证据的建议；它不接受任意查询、路径、公式或客户记录。可配置 HTTP 支持可信测试环境，但不保护传输中的凭据。单元测试覆盖传输限额、投影、规范工具结果和注销；无密钥 CRM 会话夹具通过交付的 headless 配置固定工具日志行为。

## 会话图表

可选 ui-crm 插件通过按工具名分派的 presenter 呈现 `crm_query`、固定周报工具、`crm_analyze` 和 `crm_drilldown` 的持久化元数据。生产端记录验证过的查询上下文及规范结果；图形几何和所选指标仅属于客户端。读取器在请求 Elasticsearch 前限制日历桶数量。客户端验证元数据，对失败、旧结果及畸形数据回退为文字。负金额与缺失指标保持区别。分组和语义下钻通过标准会话输入动作准备供用户确认的问题，不覆盖已有草稿。独立报表应用会重复维护会话与查询证据，因此图表使用按工具名分派的插槽。

## 动态图表请求

Agent 提供封闭集合中的图表类型和指标；客户端根据规范结果编译 ECharts 选项。不接受任意选项对象、可执行格式化函数或模型编写的数据数组。模块化 ECharts 替代自行维护的 SVG 几何，提供提示框、缩放和图形事件。展示选择不改变查询筛选条件或数值。占比视图不仅要求桶总数完整，还要求缺失维度文档数为零，因为多值维度可能通过重复归属掩盖缺失记录。渲染错误保留数据表；卸载时断开 DOM 观察器并销毁实例。单元测试执行 SVG 渲染器及其点击路径，会话回放固定 Agent 选择的展示。

分析目的与显式图表类型分别持久化，因为查询模式不足以区分结构分析和排行。Agent 按月报问题请求所需数据，客户端选择兼容图表并保留数据不完整提示。排行只作用于返回的分组，不改变取数，因此按文档数选出的分组子集不是全量金额排行。类别折线图会暗示源维度不存在的顺序，因此被拒绝。

[语义分析决策](../feature/2026-09-01-crm-semantic-analytics.zh.md)负责建立在此有限读取器之上的闭合业务目录、通用聚合请求和保留上下文的下钻。旧 `crm_query` 能力继续服务固定报表流程。
